# EXE Parser

Утилита для анализа исполняемых файлов Windows (PE-формат). Позволяет извлекать информацию из заголовков, секций, импортов и других структур PE-файлов.

## Параметры

| Аргумент | Описание |
|----------|-----------|
| `path` | **Обязательный**. Путь к анализируемому EXE-файлу (например, `C:\Program.exe` или `./app.exe`). |

## Примеры

### Базовый анализ

```bash
python pe_parser.py ./program.exe
```

### Анализ файла по абсолютному пути

```bash
python pe_parser.py "C:\Windows\System32\notepad.exe"
```
